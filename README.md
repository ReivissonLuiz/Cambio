-Conversor de Câmbio

Um site simples e funcional para conversão de moedas em tempo real. Criado com foco em praticidade e usabilidade.

-Acesse o projeto aqui: [https://reivissonluiz.github.io/Cambio/](https://reivissonluiz.github.io/Cambio/)

-Sobre o Projeto

   Este projeto exibe em tempo real o valor do câmbio de algumas moedas internacionais e permite ao usuário converter valores entre diferentes moedas por meio de um formulário intuitivo.

-Funcionalidades

   -Exibição em tempo real dos valores de:
   -Iene Japonês (JPY)
   -Dólar Canadense (CAD)
   -Euro (EUR)
   -Rublo Russo (RUB)
   -Dólar Americano (USD)
   -Conversão entre qualquer par de moedas
   -Interface responsiva

-Tecnologias Utilizadas

-HTML
   -CSS
   -JavaScript
   -[ExchangeRate API](https://www.exchangerate-api.com/)

-Como Usar

   1. Acesse a página inicial para visualizar os valores em tempo real.
   2. Clique em "Acessar" para acessar o formulário.
   3. Escolha a moeda de origem e a moeda de destino.
   4. Insira o valor e clique em "Converta" para ver o resultado.

   -É necessário estar conectado à internet, pois os dados vêm da API ExchangeRate em tempo real.
